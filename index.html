📚 HTML & CSS 기초 요약

📄 HTML 기본 구조

  • <!DOCTYPE html>: 문서 타입 선언 (HTML5)
  • <html>: 전체 HTML 문서의 루트 요소
  • <head>: 메타데이터 (제목, 인코딩, CSS 포함 등)
  • <body>: 실제 화면에 보이는 내용

🧩 HTML 주요 태그

  • <h1>~<h6>: 제목 태그
  • <p>: 문단
  • <a href>: 하이퍼링크
  • <img src>: 이미지 삽입
  • <ul>, <li>: 목록
  • <form>: 사용자 입력을 위한 폼
  • <input>: 텍스트, 버튼, 체크박스 등 입력 필드
  • <table>: 표
  • <header>, <footer>, <nav>, <section>: 시맨틱 태그

🎨 CSS 선택자 & 텍스트 스타일

  • 선택자: .class, #id, 태그명
  • font-family: 글꼴 지정
  • text-align: 글자 정렬 (left, center, right)
  • line-height: 줄 간격
  • color: 글자 색상
  • background-color: 배경 색상

📦 박스 모델 & 레이아웃

  • width / height: 너비/높이
  • padding / margin: 안쪽/바깥쪽 여백
  • border: 테두리
  • box-sizing: content-box 또는 border-box
  • display: block, inline, flex 등
  • position: relative, absolute, fixed 등
  • float: 요소를 왼쪽/오른쪽으로 띄움

⚡ 인터랙션 & 효과

  • hover: 마우스를 올렸을 때 효과
  • transition: 속성 변화 애니메이션
  • box-shadow: 그림자 효과
  • border-radius: 둥근 모서리
